 introduces the initial scaffold for the KPI Factory, a full-stack application for creating, managing, and appraising tokenized KPIs.

The implementation includes:
- Solidity smart contracts for the on-chain logic
- A Python FastAPI backend with a REST API
- A Python Streamlit frontend for user interaction
- Off-chain services for data ingestion, KPI generation, and oracle feeding
- Unit tests for the backend API
- A .gitignore file to exclude unnecessary files from version control
